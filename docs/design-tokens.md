# 디자인 토큰 (시안 이미지에서 추출한 근사값)

Figma 원본이 없어 시안 PNG(563px 폭)에서 색상을 샘플링했다. 원본 확보 시 교체한다.
`src/styles/theme.css`의 CSS 변수와 이 문서를 함께 갱신한다.

## 브랜드

| 토큰 | 값 | 용도 |
|---|---|---|
| primary | `#00d4a2` | 주요 버튼 (시작하기, 제출하기, 다음 사진) |
| logo-gradient-from | `#13fe79` | 로고 왼쪽, 진행률 바 시작 |
| logo-gradient-to | `#04cecb` | 로고 오른쪽, 진행률 바 끝 |
| splash-bg | `#000000` | 스플래시 배경 (보라·파랑 글로우 그라데이션이 얹힘) |

## 텍스트와 표면

| 토큰 | 값 |
|---|---|
| text-strong | `#111111` |
| text-muted | `#767676` |
| surface | `#ffffff` |
| surface-muted | `#f2f2f7` (칩, 비활성 배경, 입력 테두리 `#f2f2f5`) |
| chip-selected | `#222222` |
| disabled-button | `#d9d9dc` (시안 회색 버튼 근사) |

## 감정 격자 (6x6) 색상

같은 반(상단 3행 / 하단 3행)의 같은 열은 같은 색이다.

| 열 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 상단 3행 (에너지 높음) | `#ab0000` | `#f83e00` | `#ff4651` | `#ff8a37` | `#ffbb3c` | `#fddd3b` |
| 하단 3행 (에너지 낮음) | `#5a8eaa` | `#7eb1cf` | `#c8dee6` | `#c1cf95` | `#a0ac79` | `#667a37` |

## 감정 사분면 (사후 선택 v2 시안, 현재 미사용)

| 사분면 | 값 |
|---|---|
| 에너지 높음, 기분 좋지 않음 | `#ff8a37` |
| 에너지 높음, 기분 좋음 | `#f9d539` |
| 에너지 낮음, 기분 좋지 않음 | `#72a5c4` |
| 에너지 낮음, 기분 좋음 | `#909f5d` |

## 7단계 척도 얼굴 아이콘 색상 (좌에서 우, 1~7)

`#dd191c`, `#f87f28`, `#feb330`, `#e4e023`, `#9de423`, `#52d20e`, `#00d660`

## 형태

- 버튼 높이 약 56px, 모서리 반경 약 14px, 가로 꽉 참
- 카드 모서리 반경 약 24px
- 화면 좌우 여백 20px
- 폰트: Pretendard (한글), 로고 영문은 기하학적 산세리프(Outfit 계열로 추정)

## 에셋 (`docs/assets/`)

- `logo-from-mockup.png`: 스플래시 시안에서 크롭한 투명 배경 로고 (498x342). 저해상도 임시본
- `icon-192-from-mockup.png`, `icon-512-from-mockup.png`: 검정 배경 + 로고 앱 아이콘 후보
- 현재 `public/icons/`에는 단색 플레이스홀더가 들어 있다. 위 아이콘 후보로 교체하면 된다
- 원본 SVG 로고를 받으면 모두 교체한다
